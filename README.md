# niCODElas — portfolio

Portfolio professionnel de niCODElas, réalisé avec React et Vite.

## Développement local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```

Vite génère le site statique dans `dist/`. Les dossiers `node_modules/` et `dist/` sont ignorés par Git ; Cloudflare Pages peut reconstruire le site depuis le dépôt avec `npm run build` et `dist` comme répertoire de sortie.

Le dossier `public/` contient les visuels et le CV proposés par le site. Le CV est destiné à être accessible publiquement.
